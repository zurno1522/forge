# COV-008B: actual-game admission evaluation

Extend the controlled experiments to native heuristic games before selecting a production policy. Keep production Java, the ordinary reader and its seven exports unchanged. Each development JVM runs one game; experimental profiles/reasons remain unsupported for ordinary learning export. No production default, allowance or player-share change is included.

Generate an isolated AiInputContext overlay with checked source substitutions: initial funding/state registration, a gate and result/exception receipt around the existing capture body, and successful work-debit accounting. Preserve the original CAS charge loop inside a per-State development monitor so debit and cutoff snapshots agree. It adds synchronization/telemetry overhead and is not a production optimization or a deadline-neutral change. Actor records are bounded to sixteen original players, one Game and 8,192 aggregate clock/basis/timing/status groups. Overflow, unsupported preallocated states, cross-game use or missing hook receipts invalidate selection evidence. No sampled Game/Card history is retained in results.

Use PREFIX, HASH denominators four/eight, two HASH-eight salts, and the half-share reserve released once at actual public game turn 31. Hash the per-original-player capture ordinal and declared salt/player ID with the controlled experiment's fixed 64-bit mix; use no engine RNG. All capture callers, including parent/candidate/search contexts, share that actor's admission ordinal. Register reservation release on native turn/phase events before later deliveries, with a capture-entry fallback; release held work at most once and never borrow/refund it. Captures and outside-capture charges, including disclosure intake, have separate counters. Admission can change later disclosure availability because they share the same allowance.

A ticket owns successful charges made by its thread inside that capture; other charges belong to the outside-capture counter. Count returned/failed/in-flight capture attempts separately, including attempted views never published by a parent. This source denominator differs from observed trace records. At process shutdown, seal each actor under its work monitor and save a detached cutoff snapshot. Late work is outside that snapshot; do not invent exact trace-cutoff equivalence for timed-out workers. Preserve original callback errors. Source/collector reconciliation still comes from native trace accounting. Capture tickets and aggregate maps are bounded; overflow is explicit.

Wrap the existing command entry only to install shutdown telemetry and hash serialized engine RNG state without drawing from it. An unmodified-production JVM supplies an independent control with RNG metadata only. PREFIX must preserve normalized engine events, AI decisions/results and RNG state/call counts against that control for normally completed deterministic games. Other candidates receive the same comparisons. Exclude timing/run/source identifiers and inputContext fields from semantic comparisons, but retain actual assessments, actions, targets, costs and subordinate results. Report timeouts separately; their partial event sequences need not match normal/control cutoffs.

Test native damage/X and repeated-choice decks, two four-player Doctor Who/Ur-Dragon seeds, and a deliberately short Commander timeout. Record full/filtered traces, sidecars, source/collector health, pregame shuffles, actual attempts/work, and observed joint owner/boundary/chooser/clock availability with represented-profile quality. The two denominators must not be merged. CPU/storage effects from this monitored prototype are descriptive, not production overhead estimates; OPT-005 retains full measurement.

Validate candidate traces only in a fresh private reader instance whose accepted omission reasons are extended by exactly EXPERIMENT_SAMPLED/EXPERIMENT_RESERVED. Patch no source and permit no dataset output directory. Keep all ordinary structural/permission/entry/source-accounting checks. Collect the joint audit by decorating that instance's existing coverage observer. Bind sidecar policy/seed/limits/source hashes to each command, reconcile deliberate experimental contexts against attempts with honest unpublished/cutoff differences, and require full/filtered reports to agree except source-record counts. Verify the ordinary reader still rejects experimental records and that private validation cannot publish learning exports. All reports remain trainingReady=false.

Review the implementation and results for current/prior gaps before selection. COV-008C retains the production admission/omission schema, seed/counter/lifetime/overflow/privacy/bypass/concurrency design and policy selection. Controlled plus actual-game experiments inform that decision; they do not establish complete learning inputs or sustained coverage in unbounded games. COV-004 retains semantics/domains/bindings/readiness; OPT-005 retains calibrated CPU, allocation/transient heap, collector/UTF-8/physical-writer costs and separately committed optimizations.
